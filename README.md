Jasper

A curated GitHub knowledge index for AI, software engineering, hardware, and the Tiger-Lily / 6185 Companion ecosystem.

⸻

Overview

Jasper is a curated collection of GitHub repositories organized to support research, engineering, and long-term development of the Tiger-Lily and 6185 Companion projects.

Rather than serving as a simple list of bookmarks, Jasper is intended to be a living knowledge base of high-quality open-source software, reference implementations, libraries, frameworks, and engineering resources.

Jasper is the knowledge and discovery layer for the Tiger-Lily ecosystem, providing a curated index of technologies, research, and engineering resources that support the Companion platform.

⸻

Objectives

* Build a searchable engineering knowledge base
* Collect high-quality open-source repositories
* Track modern AI and LLM tooling
* Organize hardware and embedded development resources
* Maintain references for Swift, Linux, Rust, and web technologies
* Support reproducible engineering and research

Selection Principles

Repositories are selected for:

* Engineering quality
* Active maintenance
* Clear documentation
* Open-source licensing
* Long-term usefulness
* Educational value
* Practical applicability

⸻

Repository Standards

Repositories added to Jasper should:

* Be actively maintained
* Have clear documentation
* Demonstrate engineering quality
* Use an open-source license
* Be relevant to one or more Jasper categories
